# Make AI Work for You — Reader Resources

Downloadable resources for the English edition of *Make AI Work for You: A Hands-On Guide to Hermes Agent and GPT-6 Astra*, published by Happy eBook Authors.

These files are original reader aids prepared for this edition: reusable task-planning templates and a fictional practice exercise. They complement the book; they are not required to read it.

## Contents

| File | Purpose |
| --- | --- |
| [`resources/templates/task-authorization.md`](resources/templates/task-authorization.md) | Define a task's goal, inputs, allowed actions, limits, acceptance criteria, and stop conditions before delegation. |
| [`resources/templates/acceptance-handoff.md`](resources/templates/acceptance-handoff.md) | Record deliverables, verification evidence, limitations, and handoff decisions. |
| [`resources/templates/change-record.md`](resources/templates/change-record.md) | Track scope changes and the approvals they require. |
| [`resources/templates/operation-log.md`](resources/templates/operation-log.md) | Keep a local record of an agent-assisted task without storing credentials. |
| [`resources/examples/fictional-notes.md`](resources/examples/fictional-notes.md) | Synthetic source notes for a practice task; contains no real people or customer data. |
| [`resources/examples/task-brief.md`](resources/examples/task-brief.md) | A bounded task specification that uses only the synthetic notes. |
| [`resources/examples/expected-output.md`](resources/examples/expected-output.md) | Human acceptance reference for the practice task—not a model run or test result. |

## Download

Clone the repository:

```bash
git clone https://github.com/t945935/make-ai-work-for-you-resources.git
cd make-ai-work-for-you-resources
```

For a full ZIP without using Git, open the repository page and choose **Code → Download ZIP**. To save one item, open its link above and choose **Raw** or **Download**. The exercise can also be completed by reading the files in the browser; no model account, API key, or software installation is required.

## Use safely

1. Read the task brief before using an AI agent.
2. Use only the fictional notes supplied here; do not replace them with real work data.
3. Keep the expected output for human review. Do not present it as model-generated evidence.
4. Never add API keys, OAuth tokens, passwords, personal data, or confidential work material to these files or to a public issue.

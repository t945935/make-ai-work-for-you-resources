# Practice task brief

## Goal

Create `output/action-items.md` from `fictional-notes.md`, using only the facts in that file.

## Requirements

- Include each actionable task, its owner if stated, its due date if stated, its status, and a source note ID.
- Keep missing owners, dates, amounts, and decisions as **To confirm**; do not invent them.
- Record the room quote as an estimate that still needs approval, not as a purchase.
- Record the second session as a proposal, not a decision.
- Do not create, contact, or modify any external account or service. Do not browse the web or send messages.
- Do not include or request real personal data.

## Acceptance checks

1. The agenda task is assigned to Mira and its due date remains **To confirm**.
2. The accessibility check is assigned to Leon and retains the stated date, 2026-11-18.
3. The room quote and second session remain unapproved / undecided.
4. Each item links to its note ID; no unsupported fact is added.
5. Only the requested output is created. If it already exists, stop and ask before replacing it.
